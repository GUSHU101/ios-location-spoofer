# Complete Shadowrocket setup guide

[Project home](README.en.md) · [中文教程](使用教程.md) · **English tutorial** · [Coolify deployment](COOLIFY.md)

This guide is for first-time Shadowrocket users. Labels vary slightly by version, but the complete flow is always: import the module → enable HTTPS decryption → install and trust the CA → set coordinates → refresh location.

> [!WARNING]
> HTTPS decryption lets Shadowrocket inspect traffic for the matched hosts. Use it only on your own device, never export or share the CA private key, and disable the module and HTTPS decryption when they are not needed.

## Before you begin

You need an iPhone, Shadowrocket, and a working proxy configuration. No jailbreak, computer, or developer account is required.

## 1. Import and enable the module

1. Open Shadowrocket → **Config** → **Modules**.
2. Tap `+` and choose **From URL**.
3. Paste the following address and save:

   ```text
   https://raw.githubusercontent.com/GUSHU101/ios-location-spoofer/main/ios-location-spoofer.sgmodule
   ```

4. Return to the module list and confirm that **iOS Location Spoofer** is enabled.

If remote import fails, download [`ios-location-spoofer.sgmodule`](ios-location-spoofer.sgmodule) from the repository and import it locally.

## 2. Enable HTTPS decryption and trust the certificate

### Enable HTTPS decryption

A common path is **Config** → `ⓘ` beside the active configuration → **HTTPS Decryption**. Some versions place it under **Settings** → **HTTPS Decryption**.

After enabling it, confirm that the host list contains all five entries:

```text
gs-loc.apple.com
gs-loc-cn.apple.com
gsp-ssl.ls.apple.com
bluedot.is.autonavi.com
bluedot.is.autonavi.com.gds.alibabadns.com
```

Add any missing entry and save. Do not use broad wildcards such as `*.apple.com` or `*.ls.apple.com`.

### Install and fully trust the CA

1. Open **Certificate** on the HTTPS Decryption page, generate a CA, and choose to install it.
2. After iOS reports that a profile was downloaded, open **Settings** → **General** → **VPN & Device Management** and install the Shadowrocket profile.
3. Open **Settings** → **General** → **About** → **Certificate Trust Settings** and enable **full trust** for that certificate.

Installing the profile without enabling full trust usually results in `MITM failed`.

## 3. Set the target coordinates

Open Shadowrocket → **Config** → **Modules** → **iOS Location Spoofer**, edit the parameters in `argument=`, and save:

```text
latitude=39.9042&longitude=116.4074&altitude=44&horizontalAccuracy=15&verticalAccuracy=20
```

| Parameter | Purpose | Range or recommendation |
|---|---|---|
| `latitude` | Latitude | `-90` to `90` |
| `longitude` | Longitude | `-180` to `180` |
| `altitude` | Altitude in metres | Use a realistic value for the target; negatives are accepted |
| `horizontalAccuracy` | Horizontal accuracy in metres | Commonly `5` to `50` |
| `verticalAccuracy` | Vertical accuracy in metres | Commonly `10` to `1000` |
| `debug` | Diagnostic logging | Set to `true` while troubleshooting, then restore `false` |

Coordinates copied from a map are usually in latitude, longitude order. Do not swap the values.

## 4. Connect and refresh location

1. Return to the Shadowrocket home screen and connect the proxy.
2. Open iOS **Settings** → **Privacy & Security** → **Location Services**.
3. Turn Location Services off for at least 10 seconds, then turn it back on.
4. Fully close Apple Maps, reopen it, and tap the location button.

iOS can cache a previous result. If the first attempt does not change, reconnect the proxy and repeat steps 2–4 once.

## 5. Optional web map picker

Editing module parameters directly is simplest for occasional changes. For frequent changes, deploy the web picker:

| Option | Characteristics | Documentation |
|---|---|---|
| Coolify / Docker | Separate admin and module read-only secrets; suited to a public long-running service | [Coolify deployment](COOLIFY.md) |
| Cloudflare Worker CLI | No server required; command-line workflow | [Wrangler deployment](location-picker/worker/README.md) |
| Cloudflare dashboard | No server required; paste one generated file | [Dashboard deployment](location-picker/cloudflare-webui/README.md) |

After deployment, append the complete `/loc.json` address as `configUrl`. For Coolify, use the **read-only secret**, never the admin secret, in a client module.

```text
&configUrl=https://picker.example.com/loc.json?token=YOUR_READ_ONLY_SECRET
```

## Troubleshooting

### The import URL does not open

- Confirm that the repository in the URL is `GUSHU101/ios-location-spoofer`.
- Open the URL in Safari. If your network blocks `raw.githubusercontent.com`, download the file and import it locally.

### Shadowrocket reports `MITM failed`

Check these items in order:

1. The profile is installed.
2. Full trust is enabled under **Certificate Trust Settings**.
3. The failed request host is one of the five entries above.
4. HTTPS decryption and the module are both enabled.
5. Disable QUIC / HTTP3 options, reconnect the proxy, and retry.

If a new `/clls/wloc` host appears in the log, report the exact host and path in an issue. Do not add a broad wildcard yourself.

### Requests succeed but the location does not change

1. Confirm that the module is still enabled.
2. Temporarily change `debug=false` to `debug=true` and search the Shadowrocket log for `Location spoofer` or `wloc`.
3. Check that latitude and longitude are valid and not reversed.
4. If you use `configUrl`, request `/loc.json` directly and confirm that it returns the new coordinates without `401` or `403`.
5. Turn Location Services off for at least 10 seconds, reconnect the proxy, terminate Maps, and retry.

### Restore the real location

Disable the iOS Location Spoofer module or the Shadowrocket connection, then turn Location Services off and on.

### Before opening an issue

Record the client version, iOS version, failed request host, HTTP status, and raw error message, then open a [GitHub issue](https://github.com/GUSHU101/ios-location-spoofer/issues). Remove tokens, cookies, certificates, and complete private URLs first.

## Quick checklist

```text
Import and enable module → enable HTTPS decryption → install CA → enable full trust
→ edit coordinates → connect proxy → turn Location Services off for 10 seconds
→ turn it on → verify in Apple Maps
```
